Sequential Execution Example

The article begins with a basic sequential function call where a blocking sleep delays the rest of execution.

from time import perf_counter, sleep

def function1():
    print("Call made to the second function....")
    sleep(2)
    print("Second function1 execution completed...")

s = perf_counter()
print("The main function is starting...")
function1()
print("Hello World")
print("The main function ending ...")
print(f"The total time taken is : {perf_counter()-s}")

This is sequential execution: main waits until function1() completes.

Coroutine Basics: async and await

A coroutine is introduced using async def. The await keyword gives control back to the event loop so other coroutines can run while waiting.

Important syntax rules highlighted in the article:

  • await can only be used inside async def.
  • Using await outside a coroutine raises SyntaxError.
  • asyncio.sleep() is non-blocking compared to time.sleep().

Asyncio Gather Example

import asyncio
from time import perf_counter

count = 0

async def function1():
    print(f"I am function {count} printing ones")
    await asyncio.sleep(1)
    print(f"I am function {count} printing twice")

async def main():
    await asyncio.gather(function1(), function1(), function1())

if __name__ == "__main__":
    print("I am main starting..")
    s = perf_counter()
    asyncio.run(main())
    e = perf_counter() - s
    print(f"Main Executed in {e:0.2f} seconds.")

With asyncio.gather(), coroutine execution is interleaved when each coroutine reaches an await point.

Comparison: Asyncio vs Sequential vs Threading

A non-async sequential version and a threading version are compared with similar function logic.

Key conclusion from the article: async IO is a single-threaded, single-process cooperative multitasking model that can create an impression of concurrency, while threading uses actual threads.

Takeaway

Use asyncio when your workload is dominated by waiting (I/O-bound tasks) and you need efficient concurrent task scheduling without the overhead of many threads.
