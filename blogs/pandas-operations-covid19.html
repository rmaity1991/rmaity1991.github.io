Pandas Operations: Practical Data Analysis with COVID-19 Dataset

Pandas is one of the most useful Python libraries for data analysis. It provides two core data structures, Series and DataFrame, which help us clean, explore, transform, and summarize tabular data quickly.

In this post, we will go through practical Pandas operations using a real dataset: covid19_italy_region.csv. 

import pandas as pd

covid_df = pd.read_csv("covid19_italy_region.csv")

Initial Exploration

After loading data, the first step is to inspect what we have.

type(covid_df)

Output type:

  • pandas.core.frame.DataFrame

Check structure and metadata:

covid_df.info()
covid_df.describe()

Important observations:

  • Dataset has 6027 rows and 17 columns.
  • Most columns are numeric (int64 / float64), with a few object columns (Date, Country, RegionName).
  • TestsPerformed has missing values.

Get column names and shape:

covid_df.columns
covid_df.shape

Accessing Columns and Values

Extract a single column:

covid_df["NewPositiveCases"]

Check returned type:

type(covid_df["NewPositiveCases"])

Output type:

  • pandas.core.series.Series

Access a specific value:

covid_df["NewPositiveCases"][246]
covid_df.at[246, "NewPositiveCases"]

Both lines fetch the same cell value, but .at is the preferred label-based scalar accessor.

You can also use dot notation for simple column names:

covid_df.NewPositiveCases

Selecting Multiple Columns and Copying

Create a smaller view with selected columns:

cases_df = covid_df[["Date", "NewPositiveCases"]]
cases_df

Create a defensive copy before major transformations:

covid_df_copy = covid_df.copy()

Row Access with loc, head, tail, and sample

Select a row by index label:

covid_df.loc[243]
type(covid_df.loc[243])

Quickly preview top rows:

covid_df.head(5)

Preview bottom rows:

covid_df.tail(4)

Slice index range:

covid_df.loc[108:113]

Random sample for quick validation:

covid_df.sample(10)

Basic Metrics and Ratios

Compute simple high-level metrics:

total_cases = covid_df.CurrentPositiveCases.sum()
total_deaths = covid_df.Deaths.sum()

print("The number of reported cases is {} and the number of reported deaths is {}.".format(total_cases, total_deaths))

death_rate = covid_df.Deaths.sum() / covid_df.CurrentPositiveCases.sum()
print("The overall reported death rate in Italy is {:.2f} %.".format(death_rate * 100))

initial_tests = 935310
total_tests = initial_tests + covid_df.TestsPerformed.sum()
positive_rate = total_cases / total_tests
print("{:.2f}% of tests in Italy led to a positive diagnosis.".format(positive_rate * 100))

Boolean Filtering

Find rows with high daily new cases:

high_new_cases = covid_df.NewPositiveCases > 1000
high_cases_df = covid_df[high_new_cases]
high_cases_df

Create and use a calculated ratio column:

covid_df["positive_rate"] = covid_df.NewPositiveCases / covid_df.TestsPerformed
covid_df

Filter rows based on ratio threshold:

high_ratio_df = covid_df[covid_df.CurrentPositiveCases / covid_df.TestsPerformed > positive_rate]
high_ratio_df

Sorting Data

Top rows by new cases:

covid_df.sort_values("NewPositiveCases", ascending=False).head(10)

Top rows by deaths:

covid_df.sort_values("Deaths", ascending=False).head(10)

Smallest values by new cases:

covid_df.sort_values("NewPositiveCases").head(10)

Drop temporary column once done:

covid_df.drop(columns=["positive_rate"], inplace=True)

Working with Date and Time

Convert Date from object to datetime:

covid_df["Date"] = pd.to_datetime(covid_df.Date)
covid_df["Date"]

Extract useful date parts:

covid_df["year"] = pd.DatetimeIndex(covid_df.Date).year
covid_df["month"] = pd.DatetimeIndex(covid_df.Date).month
covid_df["day"] = pd.DatetimeIndex(covid_df.Date).day
covid_df["weekday"] = pd.DatetimeIndex(covid_df.Date).weekday

Now the DataFrame has additional time-based features that can be used for aggregation and trend analysis.

Aggregations with Conditions and GroupBy

Filter a month and aggregate selected columns:

covid_df_may = covid_df[covid_df.month == 5]
covid_df_may_metrics = covid_df_may[["NewPositiveCases", "Deaths", "TestsPerformed"]]
covid_may_totals = covid_df_may_metrics.sum()
covid_may_totals

Equivalent direct query:

covid_df[covid_df.month == 5][["NewPositiveCases", "Deaths", "TestsPerformed"]].sum()

Overall and conditional means:

covid_df.NewPositiveCases.mean()
covid_df[covid_df.weekday == 6].NewPositiveCases.mean()

Monthly aggregates:

covid_month_df = covid_df.groupby("month")[["NewPositiveCases", "Deaths", "TestsPerformed"]].sum()
covid_month_df

covid_month_mean_df = covid_df.groupby("month")[["NewPositiveCases", "Deaths", "TestsPerformed"]].mean()
covid_month_mean_df

Cumulative Metrics

Create cumulative columns to track progression over time:

covid_df["total_cases"] = covid_df.TestsPerformed.cumsum()
covid_df["total_deaths"] = covid_df.Deaths.cumsum()
covid_df["total_tests"] = covid_df.TestsPerformed.cumsum() + initial_tests
covid_df

Combining Datasets with Merge

Load location-level metadata:

locations_df = pd.read_csv("locations.csv")
locations_df
locations_df[locations_df.location == "Italy"]

Add merge key and join:

covid_df["location"] = "Italy"
merged_df = covid_df.merge(locations_df, on="location")
merged_df

Derive per-million metrics:

merged_df["cases_per_million"] = merged_df.total_cases * 1e6 / merged_df.population
merged_df["deaths_per_million"] = merged_df.total_deaths * 1e6 / merged_df.population
merged_df["tests_per_million"] = merged_df.total_tests * 1e6 / merged_df.population
merged_df

Conclusion

This workflow shows how Pandas can handle end-to-end data analysis tasks:

  • Data loading and schema inspection
  • Column/row indexing and scalar access
  • Filtering and sorting
  • Date conversion and feature engineering
  • Grouped aggregations
  • Cumulative metrics
  • Dataset merging and derived indicators

If you practice these operations with your own datasets, you can build strong foundations for analytics, machine learning preprocessing, and dashboard-ready data pipelines.
