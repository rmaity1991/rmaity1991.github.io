# Professional Resume + Technical Blogs Website

Static multi-page website built with plain HTML and CSS.

## Pages
- `index.html` - Home / resume overview
- `projects.html` - Project highlights
- `blogs.html` - Technical blog index
- `blogs/*.html` - Individual blog posts
- `blogs/blog-template.html` - Reusable template for new blog posts

## GitHub Pages Deployment
1. Push this folder to a GitHub repository.
2. In GitHub, open `Settings > Pages`.
3. Set source to `Deploy from a branch`.
4. Choose `main` branch and root (`/`) folder.
5. Save and wait for deployment.

## Adding New Blog Posts
1. Duplicate `blogs/blog-template.html`.
2. Rename the file (example: `my-new-post.html`).
3. Update title, content, and LinkedIn data attributes.
4. Add a new link card in `blogs.html`.
